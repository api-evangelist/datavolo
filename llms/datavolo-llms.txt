# Datavolo

> Datavolo is a dataflow infrastructure company building multimodal data pipelines for generative AI and unstructured data, powered by Apache NiFi. Founded by the original creators of Apache NiFi, it delivers fast, horizontally scalable pipelines with built-in data lineage for AI/ML and data engineering teams. Datavolo was acquired by Snowflake in November 2024.

This llms.txt was generated by the API Evangelist enrichment pipeline from the catalog profile (apis.yml). Datavolo publishes no first-party public REST API or OpenAPI specification; its platform is powered by Apache NiFi. Open-source tooling for the NiFi ecosystem is published under the datavolo-io GitHub organization.
